# 常见问题

## muslext 怎么读？

两种读法都可以：

- mus-lext：`/mʌsˈlɛkst/`
- musl-e-x-t：`/ˈmʌsəl iː ɛks tiː/`

重音可能因人而异，两种读法没有优劣之分。

## 是否提供预编译二进制？

目前不提供。muslext 以源码形式发布，由使用者针对目标系统的头文件、sysroot 和运行时 libc 构建。为某个环境构建的二进制未必适用于另一个环境。项目目前也没有维护二进制兼容矩阵，也没有为预编译产物提供长期 ABI 承诺。现在发布二进制，容易让用户误以为它是通用的。

项目构建规模很小，直接运行 `make` 即可完成构建。使用者可以用自己的工具链和参数从源码构建，成本很低。这是分发策略，不是技术上不能做。以后若建立按平台/架构验证的兼容矩阵，可以再提供预编译产物。

## 可以用于闭源或商业产品吗？

可以。muslext 使用 BSD Zero Clause License（0BSD），这是宽松许可证。它允许使用、修改和再分发，包括闭源产品，且不要求保留版权声明或许可声明。
